# business-metrics-dashboard
# Дашборд бизнес-метрик в DataLens

📝 **Полная аналитическая записка:** [analytical_report.md](./analytical_report.md)

##  Задача
Разработать информативный дашборд для мониторинга ключевых бизнес-показателей (DAU, конверсия, LTV, Retention) для сети ресторанов в г. Саранск.

## 🛠️ Инструменты
- **Yandex DataLens** — визуализация данных

## 📊 Дашборд включает

### 1. Метрики вовлеченности
- **DAU:** Динамика ежедневной аудитории за 2 месяца.
- **Retention Rate:** Удержание пользователей (общее и по месяцам).

### 2. Финансовые метрики
- **Средний чек:** Анализ изменения покупательской способности.
- **LTV ресторанов:** Сравнительный анализ пожизненной ценности ресторанов-партнеров.
- **LTV блюд:** Оценка ценности конкретных позиций меню.

### 3. Метрики эффективности
- **Коэффициент конверсии:** Доля пользователей, совершивших целевое действие.

## 🔍 Основные инсайты
- DAU и конверсия демонстрируют нисходящий тренд, что требует проверки гипотез о сезонности или UX-проблемах.
- Ресторан "Гурманское Наслаждение" генерирует наибольший LTV.
- Средний чек стабилен, что может быть как индикатором стабильности, так и точкой роста.
